
ItTechGenie - RAG Without Vector Database (Python)

Steps to Run:
1. Install Python (3.9+ recommended)
2. Install dependencies:
   pip install scikit-learn numpy

3. Run program:
   python app.py

4. Ask questions:
   Example:
   password policy
   leave policy
   insurance coverage

This project demonstrates:
- RAG concept
- In-memory document storage
- TF-IDF retrieval
- Prompt building
- No Vector Database
- No External Database
